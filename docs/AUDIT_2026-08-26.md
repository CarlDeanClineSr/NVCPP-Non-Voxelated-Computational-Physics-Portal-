## Pairing Run #7 reinterpretation

The artifact contained 4,317 paired one-minute rows. Its reported maximum Pearson correlation was approximately 0.906 at +2 minutes, while zero lag was already approximately 0.901. The 99% peak plateau covered roughly -1 through +4 minutes; daily best lags were +3, +3, and 0 minutes; first-difference correlation at the candidate lag was only about 0.082.

Therefore the supported result is:

> Strong cross-mission co-variation was present in the analyzed interval, while the propagation lag was not resolved by that analysis.

The result is not discarded. It is retained with the narrower interpretation and stronger diagnostics.

## SWiPS reinterpretation

The original SPOT/HAPI probe established that SWiPS was not listed in those queried systems at that time. The first archive V2 probe omitted the `satellite-spaceweather` bucket name, so zero returned objects did not establish an empty SWiPS archive. The corrected probe records valid bucket identity, prefix echo, pagination, raw XML hashes, and a narrow state such as `VERIFIED_EMPTY_AT_QUERY_TIME`.
